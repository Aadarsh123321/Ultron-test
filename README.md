# Practice Beyond Limits

A cinematic, responsive landing page + navigation shell for your existing CBT/test engine.

## Files
- `index.html` — app shell
- `styles.css` — UI + responsive design
- `app.js` — navigation, Google login, Firestore sync, analytics
- `script.js` - background animation
- `firebase-config.js` — paste Firebase Web App config here
- `firestore.rules` — private per-user rules

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
